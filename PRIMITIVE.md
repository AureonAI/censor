# PRIMITIVE — SCRIBA + CENSOR

O primitivo irredutível, isolado. Se tudo o mais fosse removido, isto é o que
não pode faltar sem o produto deixar de existir.

## O primitivo

**Nenhuma citação jurídica gerada por IA chega ao magistrado sem prova de que
existe, é fiel e não está invertida — verificada contra a fonte oficial.**

Tudo o mais (o SCRIBA, o C7, a interface futura) é periferia servindo a este
núcleo. O SCRIBA é substituível por qualquer gerador. O C7 é substituível por
qualquer extrator. O que NÃO é substituível é a verificação fail-closed contra
fonte primária: é ela que define o produto.

## Por que este é o primitivo, e não "gerar minuta"

Gerar minuta já é feito (MAIA/TJPE, 45,8% dos tribunais). Verificar citação na
saída de qualquer IA não é feito por ninguém. O primitivo mora na fenda, não no
território ocupado. Confundir "gerar" com o primitivo levaria a competir com o
líder no terreno dele — erro que o LIMEN proíbe (fase 2).

## Forma mínima do primitivo (o que basta para ele existir)

1. Uma citação estruturada: {número, relator, trecho, resultado}.
2. Uma fonte oficial consultável pelo número: inteiro teor do STJ (provado
   acessível, PDF-texto, sem OCR).
3. Quatro checagens fail-closed: existe / é fiel / polaridade correta / números
   conferem.
4. Um veredito com três estados honestos: CONFIRMADA / FABRICADA / NÃO-COMPROVÁVEL.

Isto é o CENSOR. É o primitivo. Tem código rodando e evidência medida.

## O que é periferia (não confundir com núcleo)

- SCRIBA (gerador) — demonstrador, substituível.
- C7 (extrator) — adaptador, substituível.
- Interface web futura — entrega, não núcleo.
- MoE real vs densa — detalhe de implementação do demonstrador, não toca o núcleo.
